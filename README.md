# React Daily Tools ⚡

A collection of small **frontend-only ReactJS apps** – daily-use tools for students, developers, and general users.  
All apps are built with **React + Vite + styled-components** and deployed on **GitHub Pages**.  
Some apps use **localStorage** for data persistence.

---

## 🌐 Live Demo

👉 [View All Projects](https://a2rp.github.io/react-daily-tools/)

---

## ⚡ Features

-   Pure **ReactJS (Vite)** frontend apps
-   **No backend required**
-   Uses **localStorage** where needed
-   Lightweight, fast, and mobile-friendly

---

## 🚀 Installation (For Local Development)

```bash
# Clone the repository
git clone https://github.com/a2rp/react-daily-tools.git

# Go into the folder
cd react-daily-tools

# Install dependencies
npm install

# Start the dev server
npm run dev
```
